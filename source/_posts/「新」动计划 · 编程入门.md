## 数学：取余

# 🔹 通用套路
1. **循环条件：`while n != 0` 或者 `while n > 0`** 只要数字还没拆干净就继续，不管是 3 位、4 位、5 位都能用。
2. **取个位、砍掉个位：平行赋值**

#### 258. 各位相加：给定一个非负整数 `num`，反复将各个位上的数字相加，直到结果为一位数。返回这个结果。
1. while 条件：（为假时退出）
2. 要得到数字的个位数用取余 %

#### 1281. 整数的各位积和之差：给你一个整数 `n`，计算并返回该整数「各位数字之积」与「各位数字之和」的差
1. 乘积初值要赋值 1，不能赋值 0
2. `n % 10` 获得最后一个数字，`n // 10` 把最后一个数去掉
3. 平行赋值：`a, b = 表达式1, 表达式2`
